# 🎯 Number Guessing Game

A simple CLI number guessing game built with Python. Try to guess the secret number between 1 and 100 in 10 attempts or less!

## ✨ Features
- 🎲 Random number between 1 and 100
- 💡 Hints if your guess is too high or too low
- 🛡️ Handles invalid inputs gracefully
- 🚪 Press `Q` anytime to quit

## 🚀 How to Run
```bash
python3 Project.py
```
